## `apps/game/src/gameplay/recording.rs`

- [Deviation] [apps/game/src/gameplay/recording.rs:1](../apps/game/src/gameplay/recording.rs#L1): Recording a game's player commands, and replaying them. A recording starts when a save is loaded (`--record FILE`). Each line of the file is one JSON entry: the start, then every [`PlayerCommand`] with the update it was given in, the updates the pause menu held the game, and, every few updates (`--record-every N`), a digest of the game state ([`super::digest`]). `unbanished --replay SAVE FILE` loads the same save without a window, carries the commands out at the same updates, and compares its digests with the recorded ones. Deviation: not in the original; recordings are a tool of the port (replays, bug reports, a step towards multiplayer). Recording and replaying run from the command line; the browser build only carries the types.
