# Play in your browser

This is the full game, built for WebAssembly. It is the same code as the desktop version.

<PlayGame />

## How to start

1. Press **Start the game**. The game downloads (about 8 MB) and shows its loading screen. It
   says where the `WinData` folder usually is.
2. Press **Choose files**. In your Banished `WinData` folder, select **all four** files at the same
   time: `data0.pkg`, `data1.pkg`, `patch0.pkg` and `patch1.pkg`. To select several files, hold
   Ctrl (Cmd on a Mac).
3. Click the game once. Then the game receives your keyboard input, and it can play sound.

## Good to know

- **Saves, settings and mods** are kept in this browser's storage for this site. They are not
  shared with the desktop version. If you clear this site's data, you delete them.
- **Mods:** select the `.pkm` files together with the four `.pkg` files, or drag them onto the game
  at any time. Then turn them on in the **Mods** menu.
- **Screenshots** (Print Screen or Scroll Lock) are downloaded by the browser.
- **Full screen:** press the **Full screen** button below the game, or check **Fullscreen** in the
  game's Options. Press Esc to leave full screen.
- **A slow computer, tablet or phone:** in the game's Options, set **Resolution** to 75 % or 50 %.
  The 3D world is then drawn smaller and scaled up, and the menus and text stay sharp. **Refresh
  rate** limits the frames per second (30 to 120); a lower value saves battery.
- **Install it as an app:** in Chrome or Edge, use the install button in the address bar (on
  Android: the browser menu, then **Install app** or **Add to home screen**). Un-Banished then opens
  in its own window and starts without an internet connection. Your game files, saves and mods
  stay as they are.
- **High-resolution screens** (4K, tablets, Samsung DeX): the menus and text are drawn on whole
  screen pixels, so they stay sharp at any display scale.
- **Mods from the internet:** the Mods menu's **Browse Nexus Mods** tab works in the browser too.
  The banishedinfo.com tab is only in the desktop version, because that site does not allow other
  web pages to read it. See [Mods](/guide/mods).
- **Multiplayer:** the **Multiplayer** button on the main menu works in the browser. See
  [Multiplayer](/guide/multiplayer).
- If the game does not start, read [Troubleshooting](/guide/troubleshooting), or
  [report the problem](https://github.com/tanepiper/unbanished/issues/new/choose).

The controls are the same as in the original game. They are listed in
[Controls](/guide/controls).
