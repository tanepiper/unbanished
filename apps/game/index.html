Banished, rebuilt from scratch, in your browser

Your game files are kept in this browser

They are kept only in this browser on this computer, and never uploaded.

Manage the game files, mods and saves kept in this browser

    On mods are used when the game starts. The order is the order they load in: a mod lower in the list wins.

        Saves from the desktop version, or from the original game, can be imported. Download keeps a copy on your computer.

        1. 1

          Find your game's WinData folder

          Un-Banished uses the files from your own copy of Banished. They are usually here:

          • Steam: …\steamapps\common\Banished\WinData (in Steam, right-click Banished, then Manage, then Browse local files)
          • GOG: the WinData folder inside the game's install folder
          • On a Mac or Linux PC: see the setup guide
        2. 2

          Choose the four game files

          Select data0.pkg, data1.pkg, patch0.pkg and patch1.pkg together.

          The files stay in your browser. Nothing is uploaded.

        3. 3

          Mods, if you like

          Select .pkm mods with the game files, or drop them on the page at any time. Turn them on in the Mods menu.
